# 🌻 Sunnybrook Farm — Cozy 3D Countryside

A charming first-person 3D cozy farming game built with **Three.js**, **TypeScript**, and **Vite**, featuring warm storybook low-poly art, dreamy HDR lighting & volumetric sunbeams, dynamic day/night cycles, procedural cozy audio, vegetable gardening, and adorable animated farm animals.

🎮 **Play Online (GitHub Pages):** https://max-2004-123.github.io/Cozy_Meadow_Farm/

## ✨ Highlights
- **Storybook Countryside World**: Arched climbing-rose entrance gate, farmhouse with glowing dormer windows & smoking chimney, red barn with rotating golden weathervane, spinning hilltop windmill, animated shader duck pond with rowboat & gazebo, wishing well, market stand, sunflowers, and distant rolling hills.
- **Vegetable Gardening**: 12 raised soil plots with till → plant → water → 4 visible 3D growth stages → harvest loop (Carrots, Radishes, Tomatoes, Pumpkins), darkening wet soil feedback, and watering-can refills at the oak barrel or pond dock.
- **Animated Farm Animals**: Chickens, cows, sheep, and pigs with solid collision, food attraction AI, happy heart reactions, and collectable eggs, milk, wool, and truffles.
- **Dreamy Lighting & Day/Night Cycle**: HDR Bloom, warm storybook color grading, volumetric sunlight shafts, animated caustic pond ripples, dusk lanterns, stars, and glowing fireflies.
- **Procedural Cozy Audio**: Web Audio API relaxing pentatonic soundtrack, gentle breeze, daytime birdsong, night crickets, pond water ambience, and animal & farming SFX.

## 🎮 Controls
| Key / Input | Action |
|---|---|
| `W A S D` | Move |
| `Shift` | Sprint |
| `Space` | Hop |
| `Mouse` / `Drag` / `Arrows` | Look around (`⚙️` for Mouse Sensitivity slider) |
| `C` | Re-center camera pitch |
| `Left-Click` / `E` | Till / Plant / Water / Harvest / Feed / Pet / Collect |
| `1–9` / `Scroll` | Select hotbar slot |
| `I` / `Tab` | Open Farm Satchel (Inventory) |
| `T` / `M` / `Esc` (`P`) | Toggle Time Speed (`1×/5×`) / Mute Audio / Pause & Settings |

## 🚀 Local Development
```bash
npm install
npm run dev
```

Build production bundle:
```bash
npm run build
```
